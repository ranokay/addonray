Optical and silhouette notes

  • The 16 px file uses the optical master: a 3.8-unit ring and a 2.8-unit accent center. The ring gap and center dot remain recognizable at 1× on both backgrounds.
  • The ring and dot carry the silhouette with a 3.82:1 to 4.99:1 primary contrast. The mint center is a secondary fill; on light chrome it is a subtle highlight, not the shape boundary.
  • The package uses one static icon. No per-theme toolbar assets, theme_icons, new permissions or manifest target changes are added.
  • Both manifests map icons and action.default_icon to 16, 32, 48, 96 and 128 px files.

This is an asset rendering proof, not store, native-OS, accessibility or distribution qualification. Companion and store compositions remain reusable material, not submission assets.
