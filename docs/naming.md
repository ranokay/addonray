# Naming research

Decision: AddonRay, repository `addonray`. Approved by the user on 2026-10-22.

“Addon” states the subject and “Ray” suggests inspection. The name remains appropriate if a later optional companion is added. It makes no promise of control over other extensions.

Authenticated repository inspection found no existing `fext`/Firefox inspector project among the account's 17 repositories. The proposed `ranokay/addonray` lookup returned not found. Repository creation must still check for a race or a newly created repo.

An unrelated historical forum username uses `addonray`. Broad web searches found no corresponding software product. These checks support practical viability and do not establish trademark clearance or domain ownership.

Rejected candidates included Weftscope, already used as WEFTScope by WEFT Security, and Addprism, used by an audio platform.
